# Crit 8 reflection

## What was the breakthrough that moved the work forward?

The real breakthrough was the idea-generation process itself --- going from
nothing to something. There were so many directions I could take, and so
many things I'm personally interested in, that the choice itself was genuinely
hard: for a project this size, something too boring risks losing motivation
later on, while something too ambitious risks being unachievable in the end.
Beyond that, on the technical side, the AI-generated work hasn't caused any
noticeable problems so far, same as usual.

## What did this work change about who I want to be as a software developer?

Making a game is something I've wanted to try for a while. This project
happened to be a small chance to actually practice it. (It's a shame the
game development course got cancelled before I had a chance to take it.)
